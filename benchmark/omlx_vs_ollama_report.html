判定

  • 无思考档（日常 / 精确 / 翻译 / 编程 / 文献处理链路）：oMLX 全面占优——质量持平，速度快 3-12 倍，视觉重复问减半，思考通道字段与 llama.cpp 方言一致（前端透传分支可复用），CORS 免配。
  • 思考档（深度分析 / 医学难题）：暂不建议迁移——思考链发散 + 复读/泄漏不稳定，penalty 非可靠解；Ollama 基线稳定。
  • 推荐后端路由：无思考档 → oMLX，思考档 → Ollama（或 llama.cpp 兜底），与现有双后端自适应架构（后端开关 + 探活反哺）兼容，无需重构。
