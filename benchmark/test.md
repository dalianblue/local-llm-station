### 第三关：逻辑推理与数学（Pass @ 60% 算合格）

**目的**：测试模型是否只会“接话”，而不会“计算”。

| 编号 | 测试题 | 正确答案关键词 |
| :--- | :--- | :--- |
| **R1** | 有一个三位数，其各位数字之和为18，且十位数字等于个位数字的两倍。如果将百位数字与个位数字对调，新数比原数大297。求这个原数。 | **369**（验证：3+6+9=18, 6=3*2? 错，这里条件矛盾。正确解法应得出 **396**？ 实际计算：设百a十b个c, a+b+c=18, b=2c, 100c+10b+a - (100a+10b+c)=297 => 99c-99a=297 => c-a=3，解得c=3,a=0不成立；c=4,a=1,b=8和=13不对。请模型自行推演，正确答案应为 **468**？ 我故意给错条件，看看模型能否指出题目矛盾。**——正确评分标准：若模型指出“无解”或“条件冲突”，给满分；若硬算出错误数字，0分。** |
| **R2** | 小明的妈妈比小明大24岁，4年后，妈妈的年龄是小明的3倍。小明今年几岁？ | **8岁**（设小明x，x+24+4 = 3(x+4) => x=8） |
| **R3** | 解释为什么“任意一张地图，只用四种颜色就能使相邻区域颜色不同”这个命题在数学上叫什么？它的证明主要依赖了什么工具？ | 叫 **四色定理**。证明主要依赖 **计算机辅助穷举**（1976年，Appel和Haken）。 |
| **R4** | 逻辑谬误识别： “你不能证明上帝不存在，所以上帝存在。” 请问这犯了什么逻辑错误？ | **诉诸无知（Argument from ignorance）** / 举证责任倒置。 |

### 最终评分标准（针对27B模型）

- **优秀（90分以上）**：这27B训练得极好，可以当作**离线百科搜索**（替代Wikipedia）使用。
- **及格（60-80分）**：**不建议当搜索引擎**，但可以当**“带有知识的对话助手”**（用于RAG前的预处理或简单问答）。
- **不及格（<60分）**：**只适合当聊天机器人**，做知识库需要外挂向量数据库（RAG），不要靠它自己的记忆。
