# Roadmap

让社区知道作者正在做什么、欢迎什么，避免重复劳动。拿不准的方向先在 issue 里对齐；想认领「欢迎 PR」条目请留言。

## 短期（1-2 个月，作者亲自做）

- **综述生成 · A 阶段**：论点式大纲（用户确认）→ 分节初稿，复用现有 ✨初稿 / [@键] 引文 / 知识卡片聚类，加篇幅与「综述比例」规则；本地 27B 逐节生成不现实，走云端（闲时计费）
- **审稿人回应助手**：上传审稿意见 → AI 标注对应修改位置 → 逐条生成回应 → 产出 point-by-point 回复信（引审稿原文 + 修改说明 + 稿件定位）。前置的审稿意见格式与报告存档已就位
- **PDF 版式兼容持续迭代**：图注锚定提取对新的期刊版式/手稿版式仍有真实失败案例，逐篇修（有提取问题的 PDF 欢迎附样本提 issue）
- **卡片引用粒度**：`[[概念]]` 目前是整卡引用，补段落/图表级粒度

## 中期（半年）

- **综述生成 · B/C 阶段**：B) 研究特征对照表自动生成 + 表格自动编号 + 罗列检测；C) 挂机检索模块（计划任务跑慢检索攒候选集 → 人工筛选入库 → 回到 A）
- **Zotero 握手深化**：BibTeX/RIS 已通，补库管理页与更顺的双向工作流
- **前端模块化**：chat/editor/dashboard 三页有大量搬运代码，必要时抽 common.js（「必要时」=下一次三页同改的痛点出现时，不为拆而拆）
- **英文文档全量同步**：README.en.md 仍是非拆分长版，待中文文档结构稳定后同步

## 欢迎 PR 的方向

（约定与硬约束见 [CONTRIBUTING.md](../CONTRIBUTING.md)）

- **PDF 提取版式兼容**：新期刊版式的提取失败案例（附样本 PDF + 期望结果），最高价值
- **新模型适配**：Qwen 系之外的多模态模型在 Ollama / llama.cpp 路线下的配置验证与方言兼容
- **UI 改进**：暗色模式、可访问性、窄屏适配
- **移植**：Windows/Linux 宿主服务实现（协议见 [PORTING.md](../PORTING.md)），参考实现被采纳后会在这里列出
- **文档与示例**：上手引导、示例项目、英文翻译

## 明确不做

写在这里是为了省你的时间——与以下方向相关的建议不会采纳：

- **多 agent 流水线**（多角色通读全文、自动多轮互改）：本地模型上多角色只是同一模型换提示词，无分工增益
- **AI 生成机制图/流程图**：产出不可校验
- **数据云端化 / 遥测埋点 / 重运行时依赖**：项目底线，见 CONTRIBUTING
- **多巴胺型 UI**（进度圆点、消息 👍/👎 反馈等）：与本站「真实判断不和稀泥」的气质相悖
- **前端多引文样式渲染**（citeproc-js，几百 KB）：Word 导出已由 pandoc 支持任意 CSL，前端维持自有 [n] 编号
