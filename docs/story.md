# 为什么要做这样一款软件（微自传，自 FAQ 迁入）

我是一名医生，我考过的试，实在太多了。托福、GRE、考研、考博，市面上超过一半的大型标准化考试我都没落下，更别提医学类的考试轮番轰炸。我甚至还参加过两次高考。第一次是2004年，语文考了140高分，总分超一本线30多分。但那时候我根本不知道自己想干什么，准确说，是不知道大学毕业后想干什么。现在回想，要是当时有张雪峰老师点拨两句，该多好。于是我又复读了一年，2005年高考，总分还是超一本线30多分——等于白忙活一年，纯粹用来思考人生。最后实在选不出来，就听了我妈的建议：学医吧。第一志愿报了南方医科大学，其实是被来高中招生宣传的那个老头忽悠的。结果那一年正好是南方医科大从军医大改制为地方大学的第一年，加上那个老头从南到北的一顿忽悠，报考人数炸了，分数线暴涨，于是落榜被第二志愿大连医科大学录取。

大连医科大学确实很美——但这句话得从2008年搬了新校区后才算成立。它之所以叫“医科大学”，是因为它还有非医学专业，比如摄影。就因为有非医学专业的存在，它才够格叫“大学”，不然就只能叫“医学院”了。我刚入学时和摄影系的同学住在一起，大一、大二基本都混在摄影圈里学拍照，兴趣浓厚。直到大三，摄影系的同学要细分方向做毕业设计了，我才不得不回到医学课堂。挂科交过重修费也拿过奖学金，矛盾的事情都占了。

真正让我对医学产生兴趣，是在研究生阶段遇到我的导师。他现在已经退休了，我是他的关门弟子，他格外关照我。有一回，他拿着教材，关上门，一对一地点拨我，教我该怎么学。就在短短半小时里，他从出题人的角度，把一整本教材的脉络讲得清清楚楚。他说，他父母是医生，他自己也教了一辈子书，这些“套路”他太熟了。那番话像一道光，让我突然找到了学习医学的正确路径。以前我深恶痛绝的名词解释，后来反而会反过来想——如果我是发明这个概念的人，我为什么要这样定义它？这个拆解的过程，让我对医学知识的理解一下子深了进去。

说这些，其实都是铺垫。我只是想表达，我的学习之路，走得挺曲折的，没啥成功经验，全是失败教训。但正是这些失败，让我对“学习”这件事有了很独特的理解。考研和考博，我的入学分数都排得比较靠前，尤其是政治，我其实不太喜欢，但每次都能考得不错。后来读博，半个脚跨进了学术圈，开始申请国自然，连着申请了五年，最后一年是我35岁，也是申请青年基金的最后机会——依旧没中。过了35岁，本以为这辈子就这么按部就班了，没想到几年后，AI突然给了我折腾的机会。

时间来到2026年，AI爆火。在AI的加持下，写软件变得易如反掌。我最初只是好奇，想测测千问3.8这个模型怎么样，它居然能在本地电脑上跑。既然能本地跑，我就顺手写了HTML前端来测试它。因为是多模态模型，又弄了篇文献来试水。一开始只是把摘要生成一张海报，没想到挺受欢迎，有小伙伴说，不如顺手把PPT功能也做了吧。等我做完从文献转PPT的功能，又有人建议：“不如把你读文献的那套学习方法也加进来。”于是我陆续加入了苏格拉底式提问，还有这些年从无数次失败中总结出来的一套方法论——能帮人迅速掌握新领域的核心知识。这款软件，就这么一步步长成了现在的样子。这个产品的逻辑，可以说是我这么多年各种“失败阅历”的凝练。

这套软件想传达的，也正是这种方法——先吃透抽象概念的本质，跟已知知识做类比，问自己它为什么这么设计，底层逻辑是什么，跟相近概念有什么关系，最后再反问：如果不这样，会怎样？用这套方法，你能在短时间内对一个新领域或新研究建立比较全面的基本认知。

从小到大，我们都听人说“要好好学习”。但学习到底是什么？我的理解是——在最短时间内，对一个知识块或知识点，获得足够深刻的理解，并内化成自己的逻辑。这，才是学习的本质。所以开发这款软件时，我心里始终有一个画面：一个坐在图书馆里，独自打开电脑、没有网络的同学。他能通过千问这样的本地大模型，当作知识库来查清概念，像维基百科一样，快速上手自己的学习任务。我多么希望，2004年的时候有人能像张雪峰一样跟我讲讲就业；也同样遗憾，当年备考的时候，没有这样一款软件能帮帮我。所以现在，我把这些遗憾和教训，连同那套“八八理论”一起，装进了这款软件里。它是我送给当年那个迷茫的自己的一份迟到的礼物，也是送给现在正坐在图书馆里、独自面对未知领域的你的一份诚意。
